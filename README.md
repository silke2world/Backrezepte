# Mein Backbuch

Diese kleine Website ist für GitHub Pages gedacht.

## Start
1. Repository auf GitHub anlegen.
2. Alle Dateien dieses Ordners hochladen.
3. Unter **Settings → Pages** `Deploy from a branch` wählen.
4. Branch `main`, Ordner `/ (root)` auswählen.
5. Speichern.

## Neues Rezept
Eine neue JSON-Datei in `rezepte/` anlegen und in `index.html` ergänzen.

## Nächster Schritt
Die Rezeptdaten können später automatisch aus Google Sheets exportiert werden. Dann bleibt Google Sheets die bequeme Eingabe und GitHub Pages die Darstellung inklusive Backmodus.
